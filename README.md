# Calculator Ore Muncă – v3.0

Aplicație Android pentru evidența și calculul orelor de muncă.

## Funcții

- Adăugare pontaj zilnic
- Calcul automat al orelor lucrate
- Calcul pentru ture care trec peste miezul nopții
- Pauză configurabilă
- Tipuri de activitate:
  - Zi
  - Noapte
  - Liber
  - Concediu
  - Medical
  - Altă activitate
- Editarea pontajelor
- Ștergerea pontajelor
- Istoric pontaje
- Situație lunară
- Normă lunară configurabilă
- Calculul diferenței față de normă
- Calculul orelor suplimentare
- Numărul zilelor lucrate
- Salvarea datelor local, fără cont și fără internet

## Tehnologii

- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- KSP
- Android SDK 35
- Java 17

## Identificare aplicație

**Package:** `ro.ciprian.calculatorore`

**Versiune:** 3.0

**Version Code:** 3

## Date

Datele aplicației sunt salvate local pe dispozitiv.

Aplicația nu necesită conexiune la internet pentru funcționarea normală.

## Compilare

Proiectul poate fi compilat automat folosind GitHub Actions.

APK-ul de test va fi generat în:

`app/build/outputs/apk/debug/app-debug.apk`
